# Kinaesthetic AI Site Rules

Read `AGENTS.md` first. These are the short operational rules:

- Site work lives in `pitch_site/*`, `site_server.py`, deploy docs, and tests.
- Do not rewrite the Streamlit cockpit in `app.py`.
- No medical claims. No raw video/audio storage.
- Make `/play` obvious in 20 seconds for players, testers, and investors.
- Default UI must be clean; advanced proof, labels, calibration, and LLM panels belong behind advanced/investor controls.
- Do not call fake/demo/offline data LIVE.
- Run the checks listed in `AGENTS.md` before declaring the site ready.
